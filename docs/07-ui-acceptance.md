## 布局检查

- 导航：正常窗口使用窄侧栏；最小窗口使用顶部标签。两种布局都能进入切换、模型、配置和更新页面。
- 配色：白色工作区与浅灰导航区分层。主要操作使用绿色，警告与错误使用独立颜色。
- 文字：页面标题保持同一层级。路径和长提示在内容区换行，不遮盖操作栏。
- 控件：新增、复制、搜索、保存和关联分开；无效输入就地提示，未保存状态保持可见。
- 滚动：模型列表与表单在小窗口仍可访问；配置报告滚动不带走底部按钮。
