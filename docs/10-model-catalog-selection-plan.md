# 模型目录文件选择计划

日期：2026-10-31。

## 范围

在模型目录页选择已有的 JSON 文件，并将路径写入所选 Codex 配置目录的 `config.toml`。选择操作只更新当前认证模式的档案，不覆盖另一模式的模型目录设置。保留现有模型目录编辑功能和其他配置字段。

## 接受条件

- 选择前验证 JSON 格式和模型字段。取消选择、验证失败或存在未保存编辑时，不写入配置。
- 在配置已经初始化时，当前模式的路径和加密档案一致；切换到另一模式再切回后，当前模式的路径仍然有效。写入失败时使用现有恢复记录恢复。
- 允许没有模式档案的目录设置模型路径；配置文件不存在时提示用户先初始化。备份不包含无关配置或凭据。
- 成功后显示所选路径和模型列表，并提示重启 Codex；更改会使旧切换预览失效。

## 验证

使用隔离配置目录验证文件选择、取消、无效文件、未保存编辑、模式切换和错误恢复。运行 Rust stable 下的格式检查、工作区 check、Clippy、测试和本地 Release 构建。使用真实 Windows 窗口和测试数据验证选择与保存，不修改用户的真实认证。

## 回滚

本功能作为独立提交。需要回滚时撤回该提交；已写入的用户配置由变更前的备份和原有恢复记录处理，不删除模型文件。
